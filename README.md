# Creator Risk Score – Cinematic Frontend

This is a **ready-to-run Next.js + Tailwind + Framer Motion** frontend for the
Creator Risk Score landing page.

## How to run

1. Unzip the folder.
2. In your terminal:

```bash
cd crs-next-frontend
npm install
npm run dev
```

3. Open http://localhost:3000 in your browser.

That's it. No extra setup commands are needed.

## Tech stack

- Next.js (Pages router)
- React
- Tailwind CSS
- Framer Motion

This project is frontend-only (no backend calls yet).
